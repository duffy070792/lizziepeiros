Fall 2012 Splash Class (week program where stuednts can teach classes to the community)

Class Description
======

The Stanford Solar Decathlon team has been working on designing and constructing a net-zero house called Start.Home. With this class we will talk about sustainable designs that we have learned about through research for this home: including water preservation, lowering energy consumption and new technologies for homes We also plan on making sustainable "gingerbread" houses (not real gingerbread, but same idea)
